# Tech Stack

## Framework & Runtime
- **Next.js 15.3.3** with App Router (latest stable)
- **React 19** (latest version)
- **Node.js** runtime

## Styling
- **Tailwind CSS v4** (latest major version)
- Custom Apple-inspired design system with CSS custom properties
- Responsive design with mobile-first approach

## Build System
- Next.js built-in build system with Turbopack for development
- PostCSS for CSS processing

## Analytics & SEO
- Google Analytics (G-FMC7N45N42)
- Comprehensive SEO metadata and Open Graph tags
- JSON-LD structured data for course schema
- Russian language optimization (lang="ru", locale="ru_RU")

## Common Commands
```bash
# Development (with Turbopack for faster builds)
npm run dev

# Production build
npm run build

# Start production server
npm start

# Linting
npm run lint
```

## Development Notes
- Uses App Router architecture (not Pages Router)
- Components are in JSX format
- Custom Apple-style color palette defined in globals.css
- Russian language content throughout
