# Product Overview

This is "Вайб-кодинг с AI" (Vibe-coding with AI) - a Russian-language educational landing page for an online course that teaches beginners how to create websites and Telegram bots using AI tools like ChatGPT and Claude.

## Key Features
- Course landing page with sections for hero, testimonials, program details, and pricing
- Lead magnet for capturing email signups
- Instructor profile (Сережа Рис / Sergey Rice)
- Focus on practical, hands-on learning without traditional coding knowledge
- Target audience: Russian-speaking beginners interested in AI-assisted development

## Domain
- Primary domain: school.hsl.sh
- Russian language content throughout
- Educational/course marketing focus
